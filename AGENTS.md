# Video production instructions

For Tech Explanasyon, use `PIPELINE.md`, the channel profile, and the relevant skills in `skills/` when they are available. The user's current instructions take precedence over stored preferences.

## Visual direction

- Favor lively 2D motion graphics with multiple purposeful moving parts that explain the narration. Use realistic imagery when it helps viewers understand the subject.
- Keep scientific and technical depictions accurate and identify illustrative reconstructions when they might be mistaken for footage of an actual device.
- Match animation cues to the existing narration and preserve the voice recording. Follow the storyboard and quality gates in the pipeline; do not describe a render as verified until its checks have actually passed.

## Learning from future video work

- When the user asks to save lessons, rules, or preferences from a conversation, use `skills/learn/SKILL.md`. Preserve existing rules, distinguish a specific example from a lasting preference, and record only supported, actionable lessons.
- Store durable video-pipeline rules in this repository so they can be restored into a future cloud workspace. Do not assume an ephemeral cloud workspace or an Antigravity slash command is automatically available in every environment.
