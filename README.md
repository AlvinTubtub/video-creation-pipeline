# Video Creation Pipeline — KAPE Explainer

The complete pipeline behind the **Tech Explanasyon** explainer films:
script → storyboard → scene builds → quality gates → ready-to-render project
for a Mac render (1080p60, 16:9).

Snapshot date: **2026-10-22** — the state after film 7 ("What Is an LLM?").
Seven films produced with this exact setup: AI agents, deepfakes (×2 versions),
AI text speed, self-driving cars, subsea fiber cables, QWERTY keyboards, LLMs.

## Layout

| Path | What it is |
|---|---|
| `PIPELINE.md` | **Start here.** The master doc: phases 0–7, folder map, setup, the seam law and every quality gate, production rules, hard-won lessons. |
| `skills/kape-explainer/` | The explainer pipeline: scaffolding, transcription, audio mastering, brand overlay, packaging scripts. |
| `skills/spatial-film/` | The film engine: presenter (mascot) builder, scene assembler, harness, seam checker. GSAP is **vendored** in `template/assets/gsap.min.js` — no CDN needed. |
| `skills/general-video/` | Frame packets and storyboard tooling. |
| `skills/hyperframes-animation/` | Animation rules and the scene blueprint library. |
| `skills/media-use/` | Media helpers. |
| `profile/` | The live channel profile: `brand.json` (Tech Explanasyon), `voice.md` (house rules), and `mascot/` — Carla, all 9 poses × blink/talk variants + the fitted `blink-fit.json`. |

## Restore / use on another machine

1. Copy `skills/*` into the agent's skills folder (e.g. `~/workspace/custom-skills/`).
2. Copy `profile/` to `~/.kape-explainer/profile/`.
3. Toolchain: Node.js 24, Python 3.12, ffmpeg. Transcription venv:
   `python3 -m venv ~/.kape-explainer/venv` then install faster-whisper + torch (CPU)
   and **pin `av==12.3.0`** (PyAV ≥14 breaks faster-whisper).
4. Narration is recorded by the channel owner (ElevenLabs voice "Zia") — never generated by API in this pipeline.
5. Final renders run on the Mac (GPU): each film ships as a ready-to-render project
   with a one-command `render.command`.

## Excluded on purpose

- Python venv, `node_modules`, `__pycache__` — rebuildable from the setup steps above.
- `profile/mascot/faces-old-2026-10-21/` — the superseded neutral-expression face cuts.
- The finished film projects themselves (scripts, audio, renders) — they live in the
  channel's project folders, not in the pipeline.
